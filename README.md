# Transaction inspector

This app allows to check all important information about your transaction, like `id`, `sig digest`, `public keys` etc.

## Project Setup

```sh
# Make sure you are in the project root directory.

# Dependency versions come from the pnpm catalogs of the npm-common-config submodule, so check it out first:
git submodule update --init

# To install project dependencies, run:
pnpm install

# To start the app in developers mode with live server included, run:
pnpm dev

# To build the application for production into dist directory, run:
pnpm build
```
